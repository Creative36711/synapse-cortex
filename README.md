# Synapse Cortex — закрытый контур проекта

Здесь живёт то, что не должно быть публичным: оркестрация ИИ-агентов (транспорт ScriptCat),
платформенные документы (ToS, модель расходов, реестр рисков) и внутренние решения.

| Репозиторий | Что внутри | Лицензия / доступ |
|---|---|---|
| [`Creative36711/synapse`](https://github.com/Creative36711/synapse) | Ядро: runtime, CLI, редактор, GameSpec, модули, рецепты, официальные инструменты агентов (Godot, медиа, моделирование) | **MIT**, публичный, писать могут только приглашённые |
| `Creative36711/synapse-cortex` (этот) | Оркестрация агентов, транспорт ScriptCat, backend мастерской, платёжная и юридическая часть | Проприетарный, закрытый |

Правило границы: **всё, что нужно автору игры, чтобы собрать и продать её без платформы, обязано
лежать в `synapse` под MIT.** Если что-то в этом репозитории начинает быть нужным для локальной
сборки — это ошибка размещения, а не повод открывать cortex.

## Быстрый старт

```bash
npm run verify        # сборка ScriptCat + guard + 72 smoke + 14 regression
```

Переменных окружения и секретов для этой проверки не требуется. Ключи Notion / Drive / GitHub
вводятся только владельцем в доверенном интерфейсе ScriptCat и в репозиторий не попадают.
