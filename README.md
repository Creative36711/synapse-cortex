# synapse-cortex

Закрытый центр управления проектом **Synapse** — AI-friendly конструктора игр на базе Godot.

Открытый репозиторий продукта: **[Creative36711/synapse](https://github.com/Creative36711/synapse)**.
Ограничение среды: один ИИ-агент имеет доступ только к одному репозиторию, поэтому работа
разделена по доступу и координируется отсюда.

## Что здесь

| Путь | Что это |
|---|---|
| `ROADMAP.md` | Дорожная карта фаз 0–9, архитектурные правила, критерии выхода |
| `DECISIONS.md` | Продуктовые, лицензионные и финансовые решения |
| `RISK_REGISTER.md` | Реестр рисков с владельцами, признаками и реакциями |
| `COST_MODEL.md` | Модель расходов, бюджетные лимиты, оценка комиссии |
| `METRICS.md` | Проверяемые показатели по фазам |
| `docs/process/` | Регламент команды, шаблоны ТЗ и карточек, профиль ScriptCat, ручные шаги |
| `docs/phase-0/` | Состояние подготовительной фазы, открытые вопросы, гайд интервью |
| `tools/script-cat/` | Переносимый userscript-транспорт цикла (Relay 1.6.0), шаблон схемы Notion, Drive Gateway |

## Текущая стадия

**Фаза 0 — подготовительная.** Цикл ScriptCat настроен как инфраструктура, но **не запускался**:
живого прогона не было. Профиль остаётся на удержании до снятия блокеров, перечисленных в
[`docs/phase-0/PHASE-0-BRIEF.md`](docs/phase-0/PHASE-0-BRIEF.md).

## Порядок чтения для нового агента

1. `AGENTS.md` — если есть в корне; иначе `docs/process/SYN-REGLAMENT.md`.
2. `docs/process/SYN-REGLAMENT.md` — инварианты проекта, зоны записи, оракул, цикл.
3. `docs/phase-0/OPEN-QUESTIONS.md` — что ещё не решено и что нельзя трогать.
4. `docs/process/SCRIPTCAT-PROFILE.md` — эталон UUID источников; проверка изоляции от Narthex.

## Жёсткие правила

- Секреты (токен Notion, GitHub-токен, ключ шлюза, пароли) не запрашиваются в диалоге и не попадают
  в чат, Git, логи, документы и PR.
- Источники, ключи и папки проекта **Narthex** к Synapse не относятся и не используются.
  Признак нарушения — UUID базы без префикса `SYN`.
- Произвольный пользовательский код не запускается как доверенный. Хеш, подпись, манифест разрешений
  и отдельный процесс песочницей не являются.
- Незапущенная или выполняющаяся проверка — не `pass`. `not run` не равно `pass`.
- Мок и локальная имитация — не живой цикл.
