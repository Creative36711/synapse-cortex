# Drive Gateway: пошаговая настройка

Как зарегистрировать проект `synapse` в шлюзе. Инструкция написана по фактическому коду
`tools/script-cat/drive-gateway.gs` (версия 1.6), а не по памяти.

**Может сделать только Мастер.** Warden не может выполнить эти шаги — см. раздел 6.

---

| Проверка | Результат |
|---|---|
| Папок `Arena` в корне Диска | **ровно одна** — `15qaNDaYhPjv8YmHO-Nf_603PlynM6oUn` ✓ |
| Папки `synapse` внутри `Arena` | **нет** ✓ |
| Проект Apps Script `Gateway` | есть — `1iyOXVe73wJx1lOzZ5xTwp110k5G3pnth_adQ2UBdWhxaSUdnYrfJuO55` ✓ |

Обе проверки критичны: шлюз **откажется** работать, если папок `Arena` несколько,
и откажется регистрировать проект, если `Arena/synapse` уже существует. Сейчас всё чисто.

**Не трогать:** существующие `Arena/logs` и `Arena/payloads` — это наследие прежней
(не проектной) раскладки. Новый проект получит **свои** `Arena/synapse/logs` и
`Arena/synapse/payloads`. Это разные папки, они не мешают друг другу.

## 1. Что нужно до начала

- [ ] Userscript `relay.user.js` установлен (`tools/script-cat/relay.user.js`).
- [ ] Профиль ScriptCat создан: `⚙ Подключения → Управление проектами → Новый профиль`.
- [ ] Поля профиля заполнены из `docs/process/SCRIPTCAT-PROFILE.md`.
- [ ] **UUID профиля скопирован.** Он понадобится в шаге 3. Без него продолжать нельзя.

Профиль остаётся на удержании до конца настройки.

---

## 2. Обновить код шлюза

В своём Apps Script проекте `Gateway` (лежит в папке `Arena`):

1. Заменить код на `tools/script-cat/drive-gateway.gs`.
2. Заменить манифест на `tools/script-cat/appsscript.json`.
3. **Прочитать манифест перед согласием.** Он запрашивает широкий доступ к Диску.
   Убедиться, что это именно твой аккаунт и именно этот код.

---

## 3. Задать настройки скрипта

`Настройки проекта → Свойства скрипта → Добавить свойство`:

| Свойство | Значение |
|---|---|
| `CF_SETUP_PROJECT_ID` | UUID профиля ScriptCat из шага 1 |
| `CF_SETUP_PROJECT_FOLDER` | `synapse` |

**Ограничения, которые проверяет код:**

- UUID — строго в формате `8-4-4-4-12` шестнадцатеричных цифр, регистр не важен.
- Имя папки — только `a-z`, `0-9`, точка, подчёркивание, дефис; от 1 до 51 символа;
  начинается с буквы или цифры; **не** `logs` и **не** `payloads`; без `..`.

---

## 4. Запустить регистрацию — один раз

В редакторе Apps Script выбрать функцию **`setupProjectGateway`** и нажать «Выполнить».

Что произойдёт:

```
Arena/synapse/          ← создаётся
├── logs/               ← создаётся
└── payloads/           ← создаётся
```

В журнале (`Просмотр → Журналы`) появится строка:

```
Project <uuid> · Arena/synapse · key (keep private): <ключ проекта>
```

**Скопировать `<ключ проекта>`** — он понадобится в шаге 6.

**Это НЕ общий ключ шлюза.** Общий `CF_GATEWAY_KEY` копировать **запрещено** — он даёт доступ
ко всем проектам сразу. Нужен именно ключ проекта из этой строки.

---

## 5. Если функция выдала ошибку

| Текст ошибки | Причина | Что делать |
|---|---|---|
| `CF_SETUP_PROJECT_ID должен быть UUID` | опечатка в UUID профиля | сверить UUID, скопировать заново |
| `CF_SETUP_PROJECT_FOLDER должен быть безопасным…` | недопустимое имя папки | использовать `synapse` |
| `Проект уже зарегистрирован` | этот UUID уже в реестре | ключ не меняется; если нужен новый — другой профиль |
| `Это имя папки уже занято проектом` | имя `synapse` занято | другое имя или разобрать реестр |
| `В корне несколько папок Arena` | дубликаты `Arena` | разобрать вручную, оставить одну |
| `Папка проекта уже существует` | `Arena/synapse` создана вручную | **не удалять папки вслепую** — сначала проверить реестр |

**Функция не идемпотентна.** При сбое она может оставить созданные папки. Не запускать повторно
вслепую — сначала посмотреть реестр (`CF_GATEWAY_PROJECTS_V1`) и содержимое `Arena`.

---

## 6. Почему это не может сделать Warden

Три причины, каждая достаточная:

1. **Техническая.** `setupProjectGateway()` — функция Google Apps Script, которая выполняется
   через `DriveApp` от имени владельца аккаунта. Доступ запускать её в твоём Apps Script есть
   только у тебя. Коннектор Google Drive не умеет выполнять Apps Script.
2. **Секрет.** Функция создаёт ключ проекта и печатает его в журнал Apps Script. Ключ — секрет;
   по регламенту его вводит владелец, я не запрашиваю и не храню такие значения.
3. **Регламент.** Регистрация проекта в шлюзе — действие только владельца, операция
   неидемпотентна и необратима.

1. `Развернуть → Новое развертывание`.
2. Тип — **Веб-приложение**.
3. **Выполнять как:** я (владелец).
4. **Доступ:** у кого есть ссылка.
5. Нажать «Развернуть» и **скопировать URL `/exec`**.

> Одного сохранения кода **недостаточно**. Пока не создано новое развертывание,
> шлюз работает на старом коде.

## 8. Подключить и проверить

1. В `⚙ Подключения` сохранить: токен Notion, URL `/exec` из шага 7, **ключ проекта** из шага 4,
   при необходимости GitHub-токен.
2. Нажать «Проверить всё».
3. `Управление проектами → Проверить подключения и разрешить работу`.
4. `ping` шлюза должен вернуть UUID и папку **именно этого** профиля, с полем
   `projectScoped: true`.

## 9. После регистрации — что нельзя делать

`projectLayout_()` проверяет расположение и имена папок **при каждом запросе**. Если что-то
сдвинуть, шлюз перестанет работать и вернёт:

```
Папки проекта перемещены или переименованы
```

Поэтому после регистрации:

- не переименовывать `Arena`, `Arena/synapse`, `logs`, `payloads`;
- не перемещать эти папки;
- **не складывать в `Arena/synapse` ничего своего** — это служебное хранилище шлюза,
  туда пишут журналы ходов и полезные нагрузки.

---

## 10. Про папку `Synapse` в корне Диска

Папка `Synapse` в корне Диска (`1frm1IMUrRbDYH3fLFLvTipcUFiCMWSTZ`) с подпапками
`docs`, `reports`, `decisions`, `assets` — **это другое, и переносить её никуда не нужно.**

| Папка | Кто создаёт | Что там | Кто пишет |
|---|---|---|---|
| `Arena/synapse/` | **шлюз**, при регистрации | `logs`, `payloads` — служжебные данные | только шлюз |
| `Synapse/` | Warden | документы, отчёты, решения, артефакты | люди и агенты |

Они не мешают друг другу: одна внутри `Arena`, другая в корне, имена разные.

**Опасность, которую нужно обойти:** если переместить `Synapse` внутрь `Arena` и переименовать
в `synapse` **до** регистрации, шлюз откажется работать — он не присоединяет существующие папки.
Поэтому папку документов не трогаем вообще.
