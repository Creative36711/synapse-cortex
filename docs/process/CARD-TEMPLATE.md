# Шаблон карточки — Synapse

Мастер или агент подготовки предлагает карточку как `Draft`. Coordinator самостоятельно оценивает,
редактирует, определяет порядок и выдаёт её как `Ready`.

```text
Запрос: SYN-<номер миссии>.<порядковый номер> · <название>
Миссия: <полное точное имя миссии>
Mission ID: <точный UUID страницы миссии>
Кому: <имя активного Executor или Auditor из базы «SYN Роли»>
Sequence: <порядок>
Dispatch State: Draft

Намерение:
<какой результат нужен и зачем. Без навязывания реализации>

Инварианты:
- <что не должно сломаться; конкретно и проверяемо>

Acceptance:
- <команда или процедура>
- <ожидаемый результат>
- <доказательство: путь к файлу, логу или артефакту>

Свободно:
<что исполнитель выбирает сам: способ, структура, имена>

Scope:
<разрешённые файлы и каталоги работы, проверок, отчёта>

Dependency:
<пусто или UUID страниц зависимых карточек через запятую>
```

## Правила заполнения

| Поле | Требование |
|---|---|
| `Кому` | Имя **активной** роли `Executor` или `Auditor` из `SYN Роли`, написанное точно так же. Обычные рабочие карточки Warden не выдаются. |
| `Mission ID` | Точный UUID страницы миссии. Похожее название — **не** привязка. |
| `Acceptance` | Локальный оракул карточки: команда + ожидаемый результат + доказательство. Непроверяемый оракул не выдаётся. |
| `Scope` | Явный список разрешённых путей. Всё остальное — чужая зона, только чтение. |
| `Dependency` | Каждый UUID — карточка **этой** миссии со статусом `Accepted` и без `Check = fail`. |
| `Sequence` | Порядок выдачи. |

## Что заполняет транспорт, а не человек

`Dispatch State` (после `Draft`), `Started At`, `Submitted At`, `Run ID`, `Recipient Agent ID`,
`Output Drive File ID`, `Payload Drive File ID`, `Ответ`, `Branch`, `Report SHA`, `Проверка`, `PR`, `Check`.

Не подменять `Output Drive File ID` ссылкой на произвольный отчёт.

## Что запрещено в карточке

- Пустые инварианты.
- Непроверяемый оракул.
- `Scope`, пересекающийся с зоной оракула без явного разрешения.
- Назначение Warden обычной рабочей карточки.
- Перенос чужих `Running`, `Run ID` или произвольного Drive ID из другого проекта.
