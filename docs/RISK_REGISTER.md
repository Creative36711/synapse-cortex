# Реестр рисков

Шкала: вероятность и влияние — низкое / среднее / высокое. У каждого риска есть триггер
пересмотра и действие. Риск без владельца — дефект реестра.

| № | Риск | Вер. | Влияние | Действие | Триггер |
|---|---|---|---|---|---|
| R-01 | Обещание «собери игру без платформы» нарушается: для сборки тихо требуется закрытый компонент | средняя | высокое | Инвариант D-004 в каждой миссии; проверка при приёмке: «собирается ли это без cortex» | любая миссия, добавляющая обязательный закрытый код |
| R-02 | Архитектура зашивает первый жанр: появляются проверки вида `if genre == ...` | высокая | высокое | Фаза 3 обязательна: второй прототип с другими правилами и другой моделью мира | второй прототип потребовал правок ядра |
| R-03 | Смешение представления и логики: смена визуальной темы меняет хитбоксы и правила | средняя | высокое | Оракул: тема меняется без изменения игровых параметров; тест сравнивает GameSpec до/после | первая визуальная тема |
| R-04 | Цикл агентов останавливается из-за зависимости от браузера Мастера (ScriptCat — userscript) | высокая | среднее | Явные паузы и вопросы вместо тихих простоев; локальные проверки не требуют браузера | любая пауза цикла дольше суток |
| R-05 | Один агент считается «независимым аудитором», хотя это тот же исполнитель | средняя | высокое | Разные роли = разные Agent URL; аудит отдельной карточкой другому агенту | карточка аудита назначена автору работы |
| R-06 | Notion/Drive-доступы выданы не той интеграции; агент видит чужие базы | средняя | высокое | Проверка «Проверить всё» + ручная сверка четырёх ID перед запуском | новая интеграция или новый профиль |
| R-07 | Секреты (токены, ключ шлюза) утекают в чат, лог, документ или PR | низкая | высокое | Правило: секреты вводит только Мастер; агент не запрашивает и не выводит | любой запрос токена агентом |
| R-08 | Расходы выходят за лимиты фаз 0–3 незаметно | средняя | среднее | `COST_MODEL.md`: всё платное — только по решению Мастера; бюджет $0 до фазы 4 | первый платный сервис |
| R-09 | Пользовательский код случайно получает исполнение на платформе | низкая | критическое | D-003; отсутствие сборки пользовательского кода на сервере до фазы 8 | любая задача «собрать проект на сервере» |
| R-10 | Правовые риски: ToS обещает то, чего платформа не делает (доля выручки, гарантии) | средняя | высокое | Черновик ToS только про бесплатное распространение до фазы 7; юридический аудит обязателен перед платежами | любая правка ToS агентом без Мастера |
| R-11 | Транспорт переписан «под проект» и потерял переносимость | низкая | среднее | Защищённая зона оракула: код script-cat меняется только отдельной миссией с зелёными пробами | правка `tools/script-cat/src/**` |
| R-12 | Godot-сборка и инструменты агентов ломаются в новой песочнице (нет GPU/дисплея) | средняя | низкое | `tools/godot/install.sh --check` в начале сессии; offscreen-режим | упавший smoke-тест |
| R-13 | Модерация и поддержка недооценены: публичная бета без процессов обработки жалоб | средняя | среднее | Процедура жалоб — обязательный пункт фазы 5, не «потом» | первая публичная публикация |
| R-14 | Расползание «универсальных абстракций»: сходство механик превращается в общий модуль | высокая | среднее | Правило: сходство механик ≠ требование объединить | третий похожий модуль |
| R-15 | Стратегические документы расходятся с фактическим состоянием репозиториев | средняя | среднее | Документы обновляются в той же миссии, что меняет поведение | приёмка миссии без обновления документов |
| R-16 | CJK-шрифты раздувают standalone-экспорт или рисуются «тофу»-квадратами | средняя | среднее | D-016: сабсеты + бюджет 25 МБ + рендер-тест на `ja`/`zh_CN`/`ko` | первая сборка со шрифтами |
| R-17 | Дрейф переводов: новые строки добавляются без перевода, интерфейс наполовину английский | высокая | среднее | CI `i18n-coverage` с порогом; ключи добавляются вместе с переводом или с явной пометкой долга | падение покрытия ниже порога |
| R-18 | Локаль начинает влиять на правила игры (перевод подменяет идентификатор) | низкая | высокое | D-015: код и параметры не переводятся; тест «смена языка не меняет состояние мира» | первый локализованный контент |
| R-19 | Поиск и сортировка в каталоге ломаются на CJK и диакритике | средняя | среднее | Нормализация + сортировка по локали; тест на `zh-Hans`, `pt-BR`, `de` перед фазой 5 | первая выдача поиска |
| R-20 | Юридический риск из-за восьми равноправных версий ToS | средняя | высокое | D-017: одна аутентичная версия, остальные «для удобства», ревью юриста до фазы 7 | публикация ToS |
